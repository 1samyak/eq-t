# EQ-T — Equity, Decoded

EQ-T is a static React/Vite concept for an equity-intelligence research platform and SARETY company.

## Run

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
```

## Redesign audit

### What was already strong
- React + Vite foundation
- Framer Motion interaction layer
- Dark financial-terminal visual language
- Thesis Engine and contradiction-oriented research model
- Responsive structure and reduced-motion support

### What was holding it back
- Too many sections read as independent cards rather than one product experience.
- The lime accent was visually repeated without enough hierarchy.
- The EQ-T identity was mostly typography rather than a distinctive mark.
- The hero needed stronger evidence of a real research instrument.
- Navigation and footer repeated the same brand treatment without enough system-level detail.

### What changed
- Added a custom EQ-T geometric brand mark and favicon.
- Added a moving market-tape layer to the hero.
- Added instrument framing, scan-line motion and data brackets.
- Upgraded the hero research panel with signal/evidence/status readouts.
- Tightened the visual system around market data, research evidence and thesis logic.
- Preserved the existing research sections and interactions rather than replacing working product concepts.
- Added a local SVG mark so the identity is scalable and not dependent on a raster logo.

## Note

The project intentionally uses illustrative mock financial data. It is a design prototype, not an investment product or source of live market data.
